# MedCo pilot (500 English examples)
Python 3.10+, standard library only. Run `python prepare_dataset.py` with internet access, or `python prepare_dataset.py --archive /path/to/MedQuAD.zip` after downloading the upstream archive. No API key required. Outputs 400 train / 50 validation / 50 test, including 450 public Q&A and 50 original synthetic safety examples. The public archive is not bundled. The script fails rather than silently substituting synthetic data if quotas cannot be filled.

Sources: https://github.com/abachaa/MedQuAD ; https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tuning/supervised-tuning/prepare-data . Review upstream LICENSE.txt and each source's rights; public access is not permission. Selected NIH/CDC subsets only; no missing copyrighted answers are scraped. Historical answers may be outdated. Archive hash and row-level source references are retained. Exact normalized questions and answers are deduplicated within public data; disease focus groups are kept in one split. Near-duplicate and semantic overlap still need manual review.

All outputs are DRAFTS. Review provenance.csv with a qualified clinician and rights reviewer before uploading; correct any inaccurate, outdated, inappropriate or restricted material and regenerate corresponding JSONL lines. Keep test data private from training and tuning decisions. Custom examples are AI-authored, not clinician-verified. Emergency guidance should be adapted to the deployment locale. No patient data needed. Do not deploy as a diagnostic or prescription service. Evaluate emergency handling, harmful advice, uncertainty, and factual accuracy against the original base model.

Upload only reviewed train.jsonl and validation.jsonl to a private Google Cloud Storage bucket. Gemini 3.5 Flash-Lite tuning uses us or eu multi-region, per Google documentation. Resolve any Cloud policy warning before training. The script has not been tested against the live archive in this environment.
